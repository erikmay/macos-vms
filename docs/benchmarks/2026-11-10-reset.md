# Reset benchmark

- Date: 2026-11-10
- Host: Apple M1 (MacBookPro17,1), 16 GB RAM, 8 cores, macOS 27.0.1, Tart 2.41.1
- VM: 4 vCPUs, 6144 MB RAM, `--no-graphics --net-softnet`, golden image from `ghcr.io/cirruslabs/macos-tahoe-base:latest`
- Command: `make reset N=2`, 3 runs; the other VM kept running

| Step | Run 1 | Run 2 | Run 3 | Median |
| --- | ---: | ---: | ---: | ---: |
| Save the logins, delete the old VM | 8 s | 5 s | 5 s | 5 s |
| Clone the golden image, launchd jobs | 3 s | 3 s | 2 s | 3 s |
| macOS boots until the Tart guest agent answers | 34 s | 34 s | 33 s | 34 s |
| Restore logins, start T3, privacy permissions, app session | 11 s | 12 s | 13 s | 12 s |
| Tunnel, pairing check | 3 s | 2 s | 3 s | 3 s |
| Claude token and test prompt, Codex check | 10 s | 10 s | 9 s | 10 s |
| **Total** | **72 s** | **69 s** | **67 s** | **69 s** |
